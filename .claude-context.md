# RL Trading - Projekt Context

## Projekt Übersicht
Professional Trading System mit RL Agent Training und Real-time Chart Server.
**Clean Architecture** mit vollständiger Test-Abdeckung.

## Architektur
### Chart Server (FastAPI)
```
Routes → Services → Repositories → Core
```
- **Clean Architecture** mit Dependency Injection
- **Repository Pattern** für Datenabstraktion
- **Service Layer Pattern** für Business Logic
- **FastAPI + WebSocket** für Real-time Charts
- **TradingView Lightweight Charts** Frontend

### RL Training
- PPO Agent mit custom Trading Environment
- Reward Shaping für profitable Strategien
- TensorBoard Integration
