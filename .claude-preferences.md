## 🚨 Process Management

### Chart Server (Port 8003)
- **Standard-Start**: Chart Server OHNE Streamlit
- **KRITISCH: IMMER alte Shell killen VOR Neustart** → Max. 1 aktive Shell
- **Restart-Workflow**:
  1. Alte chart_server Prozesse beenden: `wmic process where "CommandLine like '%chart_server%'" delete`
  2. Alte Background-Shell killen (falls vorhanden)
  3. Neue Shell starten mit `run_in_background=true`
- **NIEMALS neue Shell starten ohne alte zu killen** → verhindert Shell-Akkumulation

### Background Tasks & Shells
- **Session-Start Cleanup (KRITISCH)**: Bei JEDER neuen Session als ERSTES `/bashes` ausführen und ALLE alten Shells beenden
  - Workflow: Liste prüfen → Alle Shells mit KillShell beenden → Status verifizieren
  - Verhindert Shell-Akkumulation aus vorherigen Sessions (15 Shells → 1 Shell)
- **Automatisches Cleanup OHNE Nachfrage**: Bei Session-Start SOFORT alle alten/beendeten Background-Shells beenden
- **Proaktiv handeln, nicht fragen**: NIEMALS nachfragen ob Cleanup erwünscht - einfach machen
- **KillShell verwenden** für verwaiste Prozesse
- **Chart Server Cleanup**: `wmic process where "CommandLine like '%chart_server%'" delete` vor Neustart
- **Prevention**: Eine neue Shell NUR starten wenn vorherige gekilled wurde
