## 🚨 Process & Session Management

### ⚡ SESSION START (AUTOMATISCH!)
**Bei jeder neuen Session SOFORT & KOMPLETT ausführen (OHNE nachfragen!):**

**SCHRITT 1: Background-Shells Cleanup**
   - Alle Shell-IDs aus system-reminders sammeln
   - KillShell für jede ID aufrufen (parallel)
   - ⚠️ KEINE User-Zustimmung erforderlich - einfach machen!

**SCHRITT 2: Chart Server Prozesse killen**
   - `wmic process where "CommandLine like '%chart_server%'" delete`

**SCHRITT 3: Chart Server starten**
   - `py charts/chart_server.py` (run_in_background=true)

**SCHRITT 4: Erfolg verifizieren**
   - BashOutput prüfen für:
     - ✅ Server läuft auf Port 8003
     - ✅ AccountService initialized
     - ✅ Zeit wiederhergestellt aus Config

**⚠️ KRITISCH: Alle 4 Schritte AUTOMATISCH nacheinander ausführen!**
Workflow: Kill Shells → Kill Prozesse → Server Start → Verify (ALLES ohne User-Input!)

### 🔄 Chart Server Management
- **Standard-Start**: Chart Server OHNE Streamlit
- **KRITISCH: Max. 1 aktive Shell** - IMMER alte killen VOR Neustart
- **Restart-Workflow**: Kill Prozesse → Kill Shell → Neue Shell starten
- **NIEMALS neue Shell ohne Cleanup** → verhindert Shell-Akkumulation

### 🧹 Background Tasks & Shells
- **Proaktiv & autonom handeln** ohne User-Interaktion
- **Verwaiste Prozesse**: Automatisch mit KillShell bereinigen
- **Prevention**: Neue Shell NUR starten wenn vorherige gekilled wurde

### 📝 Bugfix Documentation
- **ALLE Bugs dokumentieren** in `docs/BUGFIX_DOCUMENTATION.md`
- **Format**: Datum, Problem, Root Cause, Fix Locations, Prevention
